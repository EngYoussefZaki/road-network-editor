Select / Edit: the editing tool. Three grab modes:
• ⬚ Whole template — drag a placed template (snaps + auto‑rotates to nearby roads like placing one).
• ● Single node — edit one joint; drag near another node/road and, on release, it welds topologically (shared node / split road) when Auto‑align is on.
• ⛓ Connected — click a joint to grab its entire connected network (roads + welded templates move together).
SHIFT‑click adds/removes nodes; drag empty space rubber‑band‑selects; SHIFT‑drag pans. Right‑click a template → Edit / Move / Duplicate / Delete. Right‑click a rail/metro segment → Surface Railway / Underground Metro / Delete. ALT cycles grab modes temporarily.
Welding: on release after a real drag, snapped geometry is merged for real (undoable). Uncheck Auto‑align for positional‑only nudges.
Snap: cyan ticks ride the curve (draw/attach only). Mid-road snaps split the road, preserving its shape.
Eraser: Hover to highlight red, click to delete.
